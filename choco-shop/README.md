# Choco Boutique — сайт шоколадного магазина

Готовый одностраничный сайт на HTML/CSS/JS с каталогом, фильтрами и корзиной (localStorage). Интерфейс и тексты — на русском.

## Запуск

- Вариант 1: просто откройте файл `index.html` в браузере.
- Вариант 2: запустите локальный сервер (рекомендуется для корректной загрузки шрифтов и картинок):

```bash
# любым удобным способом, например:
python3 -m http.server 8080 --directory /workspace/choco-shop
# затем откройте: http://localhost:8080
```

## Структура

- `index.html` — страница с секциями: хедер, герой, каталог, о нас, отзывы, контакты и корзина.
- `styles/main.css` — стили светло-темной шоколадной темы и адаптив.
- `scripts/main.js` — логика каталога, фильтры, поиск, корзина в localStorage, базовая валидация формы.

## Кастомизация

- Товары редактируются в `scripts/main.js` в массиве `productList`.
- Цвета/отступы/сетка — в `styles/main.css` (CSS-переменные в `:root`).
- Тексты и контакты — в `index.html` (разделы `about`, `contact`).
